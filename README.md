## Status

Version 7 is the current version of this paper. A revision is in progress. Two parts will change: the derivation in Section 4.4, which does not hold as a proof, and the experimental section, which will be replaced by a controlled, blind comparison. Version 9, published here on 13 November 2026, has been withdrawn by the author.
